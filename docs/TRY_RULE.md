# どうぶつしょうぎ「トライ放置」問題のまとめ

## ルールの問題点

トライは「自分のライオンが相手の一段目に入り、次の相手の番で取られなければ勝ち」と説明される。
しかし「取れる位置にトライされたのに、相手が取らなかった場合」の扱いは公式ルール文にない。

- **LPSA ルール概要**（joshi-shogi.com）: 但し書き自体がなく、「一段目に入ったら勝ち」とだけ記載。
- **ねこまど ルールペーパー**: 二次情報では「次の相手の番で取られてしまう場合はトライになりません」。
- **日本語Wikipedia**: 「移動した次の手でライオンが取られる場合は除く」。

どうぶつしょうぎには反則がなく、ライオン手放置（王手放置）も反則ではないため、「取らない」という着手は可能。
その結果、解釈が二つに割れる。

| 読み方 | 結果 |
|---|---|
| (A) 入った瞬間に判定（取られ得るなら不成立） | トライ不成立のまま続行。相手が取らなくても勝ちにならない |
| (B) 相手の一手を実際に待って判定 | 取られなかった時点でトライ成立、トライ側の勝ち |

## 各種実装での対処

いずれも「その局面が発生しないように」ルールを閉じている。閉じ方は実装ごとに異なる。

### 田中哲朗「どうぶつしょうぎの完全解析」（情報処理学会, 2009）
- 末端局面を次の順で定義:
  1. 手番側が敵ライオンを取れる局面 → 手番側の勝ち（キャッチ）
  2. 1でなく、敵ライオンが自陣にいる局面 → 手番側の負け（トライ成立）
- 守備側の手番が来た瞬間に勝敗確定。「取らない」選択肢は存在しない。
- 局面列挙も「取れる時は必ず取る」「トライしたら終了」を前提とし、見逃し局面は到達不能として除外。
- 実質: **取られる位置へのトライ = トライ側の即負け**。

### どうぶつしょうぎウォーズ（HEROZ）
- 「すすめてもすぐにライオンがつかまってしまう場合は負け」。
- **ウォーズオリジナルルール**として「トライ放置（相手がすぐキャッチされる位置にトライした時に、キャッチしないこと）はできません」と明記。
- 放置禁止を独自ルール扱いにしている点が、素のルールでは未定義であることの傍証。

### 公式アプリ（G-mode / ©北尾まどか・藤田麻衣子）
- FAQ: 「相手の駒の利きがあるところにトライは出来ません」。
- 取られる位置への着手自体を禁止（非合法手扱い）。英語版Wikipediaも同様に「王手にならない限り」と記述。

## 本プロジェクトでの運用案

実装側は完全解析・ウォーズともに「取られる位置へのトライはトライ側の負け／守備側が必ず取る」に寄せている。
ここでも、守備側が必ず取るという仕様とするのが自然だと思う。それを踏まえて`movegen`を構築するか判断する。
